# Query Sequence

## Overview

This directory contains the genomic DNA sequence used as the query for the BLASTN analysis of the human TP53 gene.

## Sequence Information

- **File:** `TP53_genomic_sequence.fasta`
- **Gene:** TP53 (tumor protein p53)
- **Organism:** *Homo sapiens*
- **Sequence length:** 19,088 bp
- **Format:** FASTA
- **Analysis tool:** NCBI BLASTN (MegaBLAST)

## Purpose

The sequence was used to identify similar nucleotide sequences in the NCBI nucleotide database and investigate its correspondence with the human TP53 genomic reference region.

## Notes

The FASTA file contains the query sequence used in this project. The BLAST results and their interpretation are documented in the `results/` directory.
