# Reference Sequences

## Overview

This directory documents the reference sequences relevant to the BLASTN analysis of human TP53 genomic DNA.

## Main Reference

- **Accession:** `NG_017013.2`
- **Description:** Homo sapiens tumor protein p53 (TP53), RefSeqGene (LRG_321), chromosome 17
- **Reference sequence length:** 32,772 bp
- **Source:** NCBI GenBank

## Purpose

The human TP53 reference sequence was used to evaluate the similarity of the query sequence, examine genomic coordinates, and relate the alignment to annotated genomic features.

Additional BLAST hits, including other human sequences and a mouse chromosome 17 sequence, are documented in `results/BLAST_TP53_top_hits.md`.

## Note

This directory contains documentation about the reference sequences. The main reference accession can be retrieved from the NCBI Nucleotide database using its accession number.
