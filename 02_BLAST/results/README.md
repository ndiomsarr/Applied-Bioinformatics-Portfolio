# BLAST Results

This directory contains the results and documentation generated during the BLASTN analysis of human TP53 genomic DNA.

## Analysis Files

### 1. BLAST Top Hits
**File:** `BLAST_TP53_top_hits.md`

Summarizes the top BLAST matches, including accession numbers, sequence descriptions, query coverage, percentage identity, E-values, and alignment scores.

### 2. Main Alignment Analysis
**File:** `BLAST_TP53_alignment_analysis.md`

Documents the main alignment with the human TP53 reference sequence NG_017013.2. It includes alignment statistics, genomic coordinates, interpretation of alignment gaps, and the preliminary biological conclusion.

### 3. Genomic Feature Mapping
**File:** `BLAST_TP53_genomic_feature_mapping.md`

Examines the relationship between the main BLAST alignment and annotated genomic features of TP53, including exons and coding regions.

## Main Findings

The main human TP53 reference match showed 100% query coverage, approximately 99.75% sequence identity, and an E-value of 0.0.

These findings support a strong sequence correspondence between the query and the human TP53 genomic region. Individual sequence differences require further interpretation in their genomic context.

## Note

The reported results describe sequence similarity and alignment statistics. They do not, by themselves, establish the biological significance of individual sequence differences.
