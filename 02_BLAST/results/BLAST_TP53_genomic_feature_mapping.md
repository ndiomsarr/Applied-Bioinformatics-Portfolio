# BLAST Mapping of TP53 Genomic Features

## 1. Objective

The objective is to map the main BLASTN alignment onto the annotated genomic features of the human TP53 gene.

## 2. Reference Information

- **Reference accession:** NG_017013.2
- **Reference length:** 32,772 bp
- **Query length:** 19,088 bp
- **Main alignment subject coordinates:** 5,061–24,130
- **Strand orientation:** Plus/Plus

## 4. Relationship to the Coding Sequence

The annotated coding sequence of the TP53 isoform a consists of several concatenated segments that include:

- 15,957–16,030
- 16,148–16,169
- 16,279–16,557
- 17,315–17,498
- 17,580–17,692
- 18,261–18,370
- 18,714–18,850
- 18,943–19,016
- 21,836–21,942
- 22,861–22,942

All those segments are within the reference interval of the main alignment.

Since the coding sequence is built by several concatenated segments, there are noncoding regions between coding segments in the genome. Thus, the alignment should not be considered to be a pure comparison of coding sequences only.

## 5. Interpretation and Limitations

The coordinate range overlap helps to establish a connection between the BLAST output and annotated TP53 genomic features. But coordinate range matching itself does not define the biological origin of the mismatches and gaps.

For exact query coordinates matching to individual reference features, the blocks of the alignment should be studied since insertions and deletions affect the coordinate matching.

## 6. Preliminary Conclusion

The main BLAST alignment contains the listed coding segments of the investigated TP53 isoform and overlaps the annotated TP53 exons. It helps to perform further analysis of the genomic sequence relationship to TP53 gene annotation.

The analysis is limited to the selected features from the reference record and does not represent the comprehensive comparison of all TP53 transcript isoforms.
